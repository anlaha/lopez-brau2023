# Replication Project Template
This repository is for a project aimed to replicate
Experiment 2 and (one of the conditions from) 3a from
'People can use the placement of objects to infer 
communicative goals' by Lopez-Brau & Jara-Ettinger 
(2023, Cognition) for the course, Psychology 201A at
UC San Diego.

The repository contains three folders: 
(i) data: which will host the data collected;
(ii) original_paper: which will host a PDF copy of
the original paper that contains the findings being
replicated here;
(iii) writeup: which will contain a Quarto Markdown
file and a rendered PDF file of the written report
of this replication project
