# Replication Project Template
This repository is for a project aimed to replicate Experiment 2 and (one of the
conditions from) 3a from 'People can use the placement of objects to infer 
communicative goals' by Lopez-Brau & Jara-Ettinger (2023, Cognition) for the 
course, Psychology 201A at UC San Diego.

The repository contains four folders: 
(i) data: there are three subfolders hosting data from pilot A (non-naive 
participants),pilot B (naive participants from SONA) and alldata (full sample 
collected from SONA - the replication report and script refers to this dataset);
(ii) images: images of the objects used in the stimuli;
(iii) original_paper: hosts a PDF copy of the original paper that contains the 
findings being replicated here;
(iv) writeup: contains a Quarto Markdown file and a rendered PDF file of the 
final written report of this replication project, including main sections of the
preregistration, code for preprocessing, visualizing (and comparing to the 
original graphs), and analyzing the replicated data

The repository also contains an "index.html" file that hosts the experiment as
presented to participants coded in JSPsych.

Zenodo DOI: https://doi.org/10.5281/zenodo.24333028
